# Morning Devotion Prototype

This repository contains a minimal mobile-first static web app demo for the Morning Devotion approval workflow.

Features
- Episode list with sample data
- Buttons: Watch, Approve, Request changes, Mark published
- Simple modal to send request-change notes
- Approval/action log per episode
- Local persistence via localStorage (demo only)

How to use
- Open `index.html` in your browser (or visit the GitHub Pages site once published).
- Tap buttons to simulate actions. Approve and publish actions update the per-episode log.
- Request changes opens a modal to enter notes.
